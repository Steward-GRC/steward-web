# The document lifecycle

This page explains how a policy or procedure moves from a first draft to a published document,
and the statuses it can hold along the way.

A document does not appear all at once. It moves through clear stages. Knowing the stages helps
you understand where a draft is and what happens to it next.

## 🔀 The main path

- **Draft** — Someone writes the first version. A draft is a work in progress, and most people
  cannot see it yet. An author may start from scratch or from a **template** that sets up the
  sections the document needs.
- **In review** — When the draft is ready, the author submits it. It enters an approval
  **workflow** and goes to the right people to decide.
- **Published** — An approver approves the document through every stage. Now it is official, and
  the people who need it can read it.

Over time, a published document may need updates. A new draft is started, and it moves through
review and publishing again, so the document stays current.

## 🏷️ All the statuses

| Status | What it means |
| --- | --- |
| Draft | Being written. Not yet submitted. Most people cannot see it. |
| In review | Submitted and moving through the approval workflow. |
| Published | Approved and official. Readers can see it. |
| Rejected | An approver turned the draft down. It did not publish. |
| Withdrawn | A published document was pulled back and is no longer in force. |
| Superseded | A newer version has taken this one's place. |

## 📐 Templates

A **template** is a reusable outline for a policy or procedure: the headings and sections a
document of that kind should have, including sections that are required. Starting from a
template means authors do not have to remember every part, and documents of the same kind stay
consistent.

A category can set a default template so new drafts there start from the same outline. A category
can also be set to **freeform**, so authors write from a blank page instead.

:::tip
Think of the lifecycle as a simple path: draft, then in review, then published. The other
statuses just describe what happens when a draft is turned down, pulled back, or replaced.
:::
