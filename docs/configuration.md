# Configuration

## Build arguments (`Dockerfile`)

| Argument            | Default         | Used for                                                                                                                                                                                                                                                                                |
| ------------------- | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP`               | none (required) | Which app's build (`staff` or `admin`) ships in the image. Becomes the runtime `APP` variable below.                                                                                                                                                                                    |
| `VERSION`           | `dev`           | Stamped into the server's health headers and, via `packages/vite-config`'s `buildInfoDefines`, into the client bundle as `__STEWARD_VERSION__`.                                                                                                                                         |
| `COMMIT`            | `unknown`       | Same as `VERSION`, as `__STEWARD_COMMIT__`. A client build with no `COMMIT` takes GitHub's `GITHUB_SHA` instead.                                                                                                                                                                        |
| `GITHUB_SHA`        | unset           | Passed to the client build only: a build with no `COMMIT` stamps this as `__STEWARD_COMMIT__`. A CI image build passes `--build-arg GITHUB_SHA="$GITHUB_SHA"`.                                                                                                                          |
| `DEV_UI_ISSUE_COPY` | `false`         | Becomes the build-time `STEWARD_DEV_UI_ISSUE_COPY_BUILD` variable below; `true` only for a local dev image. See "The dev UI-issue button" in `docs/development.md`.                                                                                                                     |
| `DEV_QUICK_LOGIN`   | `false`         | Becomes the build-time `STEWARD_DEV_QUICK_LOGIN_BUILD` variable below; `true` only for a local dev image. It also lets in the dev gate preview (`?gate=`). `pnpm run check` fails if this default changes. See "The dev quick login" and "Reaching each gate" in `docs/development.md`. |

An unstamped or blank `VERSION`/`COMMIT` falls back to `dev`/`unknown` (`COMMIT` first tries
`GITHUB_SHA`); nothing fails the build.

## Runtime environment variables (`server/`)

| Variable                            | Default                       | Used for                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP`                               | none (required)               | `staff` or `admin`; selects which app's build output and routes the server serves. Set by the Dockerfile; a direct run (outside the image) must set it too.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `PORT`                              | `3000`                        | The port the Node server listens on.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `GATEWAY_URL`                       | `http://localhost:8080/query` | The steward-gateway GraphQL endpoint for every loader, action, the `/query` proxy and the `/collab/ws` proxy, and the `/readyz` ping. Sign-in, sign-out and the session's CSRF token use the gateway's `/auth/*` routes on the same origin (the URL with `/query` stripped). The sign-in page offers the password reset, passkeys and SSO only as far as the gateway's `GET /auth/config` says; SSO sign-in sends the browser to `/auth/sso/start` on the app's own origin with the connection and the identifier; the app server passes `/auth/sso/*` through to the gateway, and the gateway's return paths (`/home`, `/login`) land on the app's home and sign-in. |
| `VERSION`                           | `dev`                         | Read back into the `Steward-Version` health header (see `docs/runbook.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `COMMIT`                            | `unknown`                     | Read back into the `Steward-Commit` health header.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `STEWARD_DEV_UI_ISSUE_COPY`         | unset                         | The root loader's gate for the dev UI-issue button: `true` renders it, anything else doesn't. Only takes effect on a build also made with `DEV_UI_ISSUE_COPY=true`; see "The dev UI-issue button" in `docs/development.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `STEWARD_DEV_QUICK_LOGIN`           | unset                         | The server switch for the dev quick login on the sign-in page and the thin "Dev login, test users only" bar on every other page: `true` turns both on. Only takes effect on the dev server or a build made with `DEV_QUICK_LOGIN=true`; a release image ignores it.                                                                                                                                                                                                                                                                                                                                                                                                   |
| `STEWARD_DEV_QUICK_LOGIN_USERS_DIR` | unset                         | Path to a directory with one JSON-object account per file (the shape a Kubernetes Secret volume mounts, one key per account). Takes priority over `STEWARD_DEV_QUICK_LOGIN_USERS` when both are set. See `docs/development.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `STEWARD_DEV_QUICK_LOGIN_USERS`     | unset                         | Path to the dev quick login's local JSON users file (see `docs/development.md`). Read on the server only; the page never sees a password.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `STEWARD_DEV_MOCK_URL`              | unset                         | Where the dev quick login finds steward-mock-server, whose managed people it lists and signs in (`/_mock/people`, `/_mock/controls`). Unset, it looks at `GATEWAY_URL`'s address, since the mock answers both. Dev server or `DEV_QUICK_LOGIN=true` build only; see "The dev quick login" in `docs/development.md`.                                                                                                                                                                                                                                                                                                                                                   |
| `STEWARD_REPORTING`                 | unset                         | `true` turns on the compliance reporting case pages (`/reporting/cases`), their home link, the staff sidebar's Compliance section and the admin rail's Compliance group; anything else leaves them answering not found. Off for rc.1: the case pages are redesigned in a later release.                                                                                                                                                                                                                                                                                                                                                                               |
| `STEWARD_ENVIRONMENT`               | unset                         | Names a non-production install for the hatched environment banner at the top of every page ("test" shows a TEST tag and "Test environment"). Unset, or `production`, shows no banner.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `STEWARD_ORGANISATION`              | unset                         | The organisation's name for the header's organisation slot and the footer ("© 2026 Example Organisation · Steward"). Unset leaves the slot out.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `STEWARD_DOCS_URL`                  | `https://steward-grc.com`     | Where the header's Docs link goes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `STEWARD_ADMIN_URL`                 | `/admin`                      | Staff only. Where the header's Admin link goes; it shows only to people with a way into the admin app.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `STEWARD_STAFF_URL`                 | `/`                           | Admin only. Where the admin header's Staff link goes back to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Build-time only (never set on a live build)

| Variable                          | Default | Used for                                                                                                                                                                                                                                                                                                        |
| --------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STEWARD_DEV_QUICK_LOGIN_BUILD`   | unset   | Set from the `DEV_QUICK_LOGIN` build argument. `packages/vite-config`'s `chooseDevelopmentQuickLogin` aliases the dev quick login's users-file reader and picker, and the dev gate preview, in only for the dev server or when this is `"true"`; otherwise no-ops, so their code never reaches a release build. |
| `STEWARD_DEV_UI_ISSUE_COPY_BUILD` | unset   | Set from the `DEV_UI_ISSUE_COPY` build argument. `packages/vite-config`'s `chooseDevUiIssueButton` aliases the real dev UI-issue button in only when this is `"true"`; any other value (including unset) aliases in a no-op, so the button's code never reaches a build that didn't ask for it.                 |

## Configuration that is not an environment variable

- The gateway schema pin (`STEWARD_GATEWAY_REF`, `STEWARD_GATEWAY_SCHEMA_SHA256`) lives in
  `packages/api-client/schema-refs.env`, a committed file, not a runtime setting. See
  "Calling other services" in `docs/runbook.md`.
